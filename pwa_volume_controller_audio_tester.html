How This PWA Works

📱 System Physical Buttons vs App Volume:

Due to mobile OS security restrictions (iOS & Android), web apps and PWAs control Audio Engine Volume. Your device's physical hardware buttons set the Master Speaker Volume Limit.

📦 PWABuilder Ready Instructions:

  1. Save this file as index.html.
  2. Deploy to GitHub Pages, Netlify, or Vercel (HTTPS required).
  3. Paste your URL into PWABuilder.com.
  4. Click Build My PWA to generate Android APK/AAB or iOS package files!
